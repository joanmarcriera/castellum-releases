# Castellum: website and releases

This repository serves the Castellum website (https://castellummail.com, GitHub Pages) and hosts the
signed, notarised downloads of Castellum, an email client for macOS that keeps your mail, and any AI that
reads it, on your own Mac.

The source code is public: https://github.com/joanmarcriera/castellum-app

## Download

From version 0.4.0, releases are published with the source code:
[castellum-app releases](https://github.com/joanmarcriera/castellum-app/releases/latest). This repository keeps
versions up to 0.3.6 and hosts the website.

- macOS 13 or later, universal build (Apple silicon and Intel)
- Signed with an Apple Developer ID and notarised by Apple
- Verify the download against the published `SHA256SUMS.txt`

## Install

1. Open the `.dmg` and drag **Castellum** into **Applications**.
2. On first launch, if macOS asks, right-click the app and choose **Open**.

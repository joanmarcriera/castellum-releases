# Castellum — Releases

Official signed, notarized downloads for **Castellum**, a private AI-powered email client for macOS.

🌐 Website: **https://castellummail.com**

## Download

Grab the latest `.dmg` from the [**Releases**](https://github.com/joanmarcriera/castellum-releases/releases/latest) page.

- **macOS 12+**, Apple Silicon (M1–M4)
- Signed with an Apple Developer ID and notarized by Apple (Gatekeeper-approved)
- Verify the download against the published `SHA256SUMS.txt`

## Install

1. Open the `.dmg` and drag **Castellum** into **Applications**.
2. On first launch, if macOS asks, right-click the app → **Open**.

This repository hosts **release binaries only**. The application source is private.
